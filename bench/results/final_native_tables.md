**計時口徑**
- 主比較 = core（原生求解時間）：native 用 C++ 內部 steady_clock（含建表、搜尋，不含讀檔、行程啟動）；SAT / CP-SAT 用 solve_s（只含求解器呼叫，不含 Python 建模）。
- 端到端 = e2e：native 與 core 相同（建表在計時內）；SAT / CP-SAT = build_s + solve_s（含 Python 建 CNF／模型、建立求解器物件）。兩者都不含直譯器啟動與 import。
- 逾時 10s；PAR2 把逾時算 20s；任一次 repeat 逾時即整筆 TIMEOUT。格式：中位／最大／超時／PAR2，中位與最大只算有完成的題，粗體 = 該列 PAR2 最小。
- 單位：us = 微秒，ms = 毫秒。native 的 count 模式不儲存解，只回報解數，所以 count 的正確性檢查是「解數 = 參考解數」。
- 工作量（與語言無關）：native = 搜尋節點數；CaDiCaL = conflicts / decisions / propagations（pysat accum_stats）；CP-SAT = branches / conflicts（solver.num_branches / num_conflicts）。工作量只統計有完成的題。

**正確性**：共 5255 筆 row，每一筆都與參考比對（獨立參考 bench.reference；無獨立參考的 S3/S4 題用 SAT 雙確認的類別；S5/S5b/S6 為唯一解、參考由 SAT+CP-SAT+bitmask 確認）。
- MISMATCH 0、ERROR 0、無參考/卡住 0、逾時 215、OK 5040。
- 沒有任何 MISMATCH / ERROR 題 id 需要列出。
- 只確認到類別（0/唯一/>=2）的題（S3/S4 中無獨立參考者）在 count 模式只比較 min(解數,2)；其餘 count 與獨立參考的精確解數一致。
